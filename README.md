# AYA EC - Página inicial del sitio web

Proyecto estático desarrollado con HTML5, CSS3 y JavaScript.

## Estructura
- `index.html`: página inicial completa.
- `styles.css`: línea visual, responsive design y componentes.
- `script.js`: menú móvil, animaciones y confirmación de formulario.
- `assets/`: ilustraciones SVG originales.
- `pages/`: páginas independientes base para cada botón del menú.

## Uso
Abrir `index.html` en un navegador moderno. Para publicar, subir todo el contenido de la carpeta a un hosting estático o al directorio público del hosting.
